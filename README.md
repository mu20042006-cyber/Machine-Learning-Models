# 🤖 Machine Learning Models

## 📌 Project Overview

This repository contains a collection of **machine learning notebooks** that cover both **supervised and unsupervised learning techniques**.  
The project demonstrates the practical application of different ML algorithms, focusing on model training, evaluation, and comparison.

Each notebook is designed to be **self-contained**, including data preprocessing, model implementation, and performance analysis.

---

## 📘 Notebooks Description

### 🔹 Classification Models
This notebook focuses on **classification problems** and includes the following algorithms:

- **Logistic Regression**  
  Used as a baseline linear classifier to predict categorical outcomes.

- **Random Forest Classifier**  
  An ensemble learning method that improves performance by combining multiple decision trees.

The models are evaluated using appropriate classification metrics to compare their performance.

---

### 🔹 Clustering Models
This notebook covers **unsupervised learning techniques** used for data exploration and pattern discovery:

- **K-Means Clustering**  
  Partitions data into predefined clusters based on similarity.

- **DBSCAN**  
  Density-based clustering algorithm capable of identifying arbitrary-shaped clusters and noise.

These models help analyze the underlying structure of the data without labeled outputs.

---

### 🔹 Regression Models
This notebook focuses on **regression tasks** for predicting continuous values:

- **Linear Regression**  
  A fundamental regression model used to understand linear relationships between variables.

- **Elastic Net Regression**  
  A regularized regression technique that combines L1 and L2 penalties to handle multicollinearity and feature selection.

Regression performance is analyzed using error-based evaluation metrics.

## 📊 Model Evaluation

Different evaluation metrics are used depending on the task:

- **Classification:** Accuracy, Precision, Recall  
- **Regression:** Mean Absolute Error (MAE), Root Mean Squared Error (RMSE)  
- **Clustering:** Inertia, Silhouette Score
